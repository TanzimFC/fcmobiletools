# FCMOBILETOOLS Company Operating System

**Status:** Version 1.0, startup stage  
**Founder and owner:** Tanzim  
**Operating budget:** $0  
**Business:** FCMOBILETOOLS, an independent FC Mobile tools and information website at https://fcmobiletools.online

This handbook establishes how the project is managed while it has no payroll budget. It is an operating framework, not a claim that FCMOBILETOOLS is a legally incorporated company or that contributors are employees.

## Mission

Build useful, accurate, fast and trustworthy FC Mobile tools and resources. Protect users, protect the project, and earn the right to grow through reliable work.

## Operating principles

1. User trust before traffic. Correct expired codes and event details quickly.
2. No spending without approval. The default approved budget is $0.
3. No promises of wages, equity, prizes or future employment unless separately agreed in writing by the owner.
4. Every task has one owner, a clear outcome and a due date.
5. Important changes are reviewed before release.
6. Access is granted by role, limited to what is needed and removed when no longer needed.
7. Reports use evidence and numbers, not vanity metrics.
8. Volunteers can decline tasks and leave without retaliation. Agree realistic availability first.
9. Security incidents, user-data exposure, account compromise and misleading public claims are escalated immediately.
10. Keep records in free tools already available. Do not create a new paid dependency.

## Decision authority

Tanzim remains the owner and final decision-maker for brand, strategy, budgets, legal commitments, production access and high-risk incidents. Delegated leads can make routine decisions within written limits. No volunteer may sign contracts, promise compensation, access private data unnecessarily or spend money on behalf of FCMOBILETOOLS without explicit approval.

## Review

Review this handbook monthly during the first 90 days, then quarterly. Record each change in Git history. Never store passwords, API keys, private user data or security secrets in this documentation.
