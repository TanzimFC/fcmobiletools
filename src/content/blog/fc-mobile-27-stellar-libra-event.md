## What is Stellar: Libra?

Stellar: Libra is a Zodiac-themed chapter of the new **Stellar Series** in FC Mobile 27.

Instead of using the same structure as a large traditional event, Stellar focuses on a smaller set of featured player items and a dedicated Draft experience.

The Libra chapter is the current live chapter and is connected to the wider FC Mobile 27 anniversary period.

The important new pieces are:

- The Stellar Draft
- Stellar Draft Vouchers
- Libra Tokens
- A seven-player Stellar Libra pool
- Event progression connected to the Libra chapter

## When does Stellar: Libra end?

The current Libra event window runs from **September 24 through October 22, 2026**.

Because live FC Mobile events can receive changes during their run, the in-game timer should always take priority over an older screenshot or article date.

## How does the Stellar Draft work?

The **Stellar Draft** is the main Draft-based feature attached to the new Stellar system.

The important difference from a normal FC Mobile Draft is the dedicated Stellar context and the separate voucher system connected to it.

## What is the Stellar Draft Voucher?

<div class="article-inline-icon"><img src="https://res.cloudinary.com/b0qikv7n/image/upload/v1790528955/fc-mobile-tools/kac9t1aomu9fohcx9ln7.png" alt="Stellar Draft Voucher icon" loading="lazy" /></div>

The **Stellar Draft Voucher** is a special item associated with the Stellar Draft.

It is not the same item as the normal Draft Voucher.

That distinction is important because players have reported cases where entering a Stellar Draft can consume a regular Draft Voucher instead of the Stellar-specific voucher they expected to use.

For a full explanation, see the [**Stellar Draft Voucher Guide**](/blog/stellar-draft-voucher-fc-mobile/).

## Stellar Libra Tokens

<div class="article-inline-icon"><img src="https://res.cloudinary.com/b0qikv7n/image/upload/v1790528952/fc-mobile-tools/ub8pjpygijyy6a4qcdyd.png" alt="Stellar Libra Token icon" loading="lazy" /></div>

**Libra Tokens** are the event-specific progression currency used by Stellar: Libra.

They should not be confused with either Draft Voucher.

The basic distinction is:

| Item | Role |
| :--- | :--- |
| **Libra Token** | Stellar: Libra event progression and rewards |
| **Stellar Draft Voucher** | Stellar Draft entry |
| **Regular Draft Voucher** | Standard Draft entry |

This separation is one of the most important things to understand before spending event resources.

## How do you get Libra Tokens?

The live event connects Libra Tokens to the **Stellar: Libra progression and reward system**.

Because the live distribution has generated confusion and reports of missing rewards, a fixed daily or weekly Token schedule should not be treated as universal unless the current in-game event explicitly shows it.

Use the current reward path visible on your own account as the immediate reference.

For the full troubleshooting guide, see [**FC Mobile Stellar Libra Tokens Guide**](/blog/stellar-libra-tokens-fc-mobile/).

## Missing Libra Tokens

Some players have reported that an expected Libra Token does not appear after a reward or login-related step.

The issue can present as:

- A reward looking claimed while the Token balance does not change
- An expected Token not appearing on a new day
- Different Token totals between players
- A reward appearing before the balance visibly updates

When this happens, first reopen the game, check the Stellar: Libra page again and verify that the reward was actually claimed.

If a larger number of players are reporting the same issue at the same time, the problem may be related to live event data rather than an individual account.

## The current Stellar Draft Voucher issue

The other major point of confusion is voucher consumption.

Players have reported that a Stellar Draft attempt can reduce their **regular Draft Voucher** balance.

That is important because the regular voucher and Stellar voucher are supposed to represent different parts of the Draft system.

Until the live behavior is fully clarified or changed, check the voucher balance shown by the Draft screen before making several attempts.
