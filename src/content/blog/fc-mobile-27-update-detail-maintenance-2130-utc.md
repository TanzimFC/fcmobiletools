## FC Mobile 27 maintenance schedule

FC Mobile 27 is moving into its new season, and players will need to wait through scheduled server maintenance before the updated game becomes available.

The planned maintenance window is approximately **4.5 hours**:

**21:30 UTC → 02:00 UTC**

The **02:00 UTC** time is an estimate. It is not a guaranteed server reopening time, so FC Mobile may remain unavailable for a while after the scheduled end.

## When does FC Mobile 27 maintenance start?

FC Mobile 27 maintenance is scheduled to begin at:

**21:30 UTC on September 23, 2026**

The maintenance is expected to run for around 4.5 hours, putting the estimated return time at:

**02:00 UTC on September 24, 2026**

The new season is scheduled for September 24, alongside the game's third-anniversary content.

## What if FC Mobile is still down after 02:00 UTC?

Don't panic if the game does not immediately come back online at the estimated time.

The **4.5-hour maintenance period is an estimate**, and FC Mobile maintenance can sometimes take longer than the initial schedule. Delays of 15–30 minutes can happen, while longer delays are also possible.

If the game is still unavailable:

1. Wait a little longer for the maintenance to finish.
2. Check for an updated maintenance announcement.
3. Try restarting FC Mobile once the servers are expected to be back.
4. Avoid reinstalling the game simply because the estimated maintenance time has passed.

A delayed server opening does not necessarily mean there is a problem with your account or device.

## Why does FC Mobile maintenance happen?

Scheduled maintenance gives the developers time to deploy the new season and make server-side changes before players return to the game.

For a major seasonal update, maintenance can involve multiple systems, including game content, events, player data, services and other backend components.

That is why the published end time should be treated as an **expected return time**, rather than a guarantee.

## What is coming with FC Mobile 27?

The maintenance is part of the transition into the FC Mobile 27 season.

The new season is also tied to FC Mobile's **third-anniversary celebration**, with new seasonal content and changes arriving around the launch.
