The **Stellar Libra Token** is the event-specific progression item used in the **Stellar: Libra** chapter of FC Mobile 27.

It is easy to confuse the Token with the event's Draft Voucher because both appear inside the same Stellar content. They are not interchangeable. The Token is tied to the event's progression and reward structure, while the Stellar Draft Voucher is tied to Draft entry.

There is also an important live issue to understand: some players have reported that an expected Libra Token does not appear after a reward or login-related step.

This guide focuses on the Token itself and the practical checks you can make on your account.

## What is the Stellar Libra Token?

The Libra Token is a **Stellar: Libra event currency**.

Its role is connected to the event's progression and reward paths rather than the standard FC Mobile economy.

That makes it different from familiar currencies and items such as Coins, Gems and Draft Vouchers.

## Libra Token vs Stellar Draft Voucher

These two items are related to the same event, but they do different jobs.

If you are trying to open the Stellar Draft, look at the Draft requirement.

They should never be treated as one currency.

## Where should you look for Libra Tokens?

The exact presentation can change as the live event receives updates, so check the areas connected to Stellar: Libra first.

### 1. Stellar: Libra event progression

Open the Stellar: Libra content and review the current reward or progression track.

### 2. Claimed rewards

If a Token comes from a reward you just claimed, make sure the reward actually completed before leaving the screen.

### 3. Store and event-linked sections

The anniversary and Stellar content can be distributed across more than one menu, so check the event-specific areas rather than relying on one shortcut.

### 4. Your current Token balance

Always verify the balance after a successful claim.

This is particularly important when the event is being adjusted server-side.

## How do you get Libra Tokens?

The live Stellar: Libra system connects Tokens to **event progression and reward claims**.

However, players should be careful with fixed Token schedules shared in community posts. The live distribution has produced enough confusion that a schedule should only be treated as reliable when the game itself shows it or a later update confirms it.

For the same reason, this guide does not invent a guaranteed daily or weekly Token amount.

## The missing Libra Token issue

Some players have reported an expected Libra Token not appearing after an event or login-related reward.

The reports generally fall into a few patterns:

- A reward appears to be claimed but the Token balance does not change.
- A player expects a Token on a new day and does not see it.
- Different accounts appear to show different Token totals.
- A reward is visible in the event but is not immediately reflected in the balance.

Because the event is live and can be updated without a full client update, the safest approach is to verify the reward state before assuming the Token has been permanently lost.

## What to do when your Libra Token is missing

### Step 1: Reopen FC Mobile

Fully close the game and open it again.

This can refresh event data that did not appear immediately after a claim.

### Step 2: Recheck the Stellar: Libra page

Open the event again and look at the exact reward or progression step involved.

### Step 3: Check whether the reward was actually claimed

A reward that is visible is not necessarily the same as a reward that has already been credited.

### Step 4: Check the Token balance

Compare the balance before and after the claim if possible.

### Step 5: Wait for the event data to refresh

Live event systems can update independently of the main game client. If several players are reporting the same problem at the same time, it may be a server-side issue rather than an account-specific problem.

Do not spend or use other event items while you are still trying to establish whether the Token was credited.

## Is there a guaranteed daily Libra Token?

This is one of the most confusing questions around the event.

Community discussions have proposed different Token schedules, but the live experience has not been consistent enough to publish a fixed daily number as a universal rule.

For now, use the **reward shown in your own live event account** as the immediate source of truth.

That also makes this page easier to keep accurate when EA changes the event during its run.

## Can Libra Tokens be used for the Stellar Draft?

The Token and the Draft Voucher are separate items.

A Libra Token should not be assumed to function as a Draft entry ticket just because both are part of Stellar: Libra.

The dedicated Draft entry system uses the **Stellar Draft Voucher** or whatever voucher the live Draft screen currently shows.

## Why are Token counts different between players?

There are several possible reasons for different balances:

- Different claims were made at different times.
- A player missed a reward.
- A reward did not display immediately.
- The live event changed after maintenance.
- An account may be affected by a current reward-delivery issue.

Because of that, comparing another player's screenshot with your own balance is useful for spotting a problem, but it does not by itself prove what your account should have received.

## Do not confuse the Token with a Draft Voucher

This is worth repeating because both items appear in the same event.

**Libra Token**

Used for event progression and rewards.

**Stellar Draft Voucher**

Used for the Stellar Draft system.

**Regular Draft Voucher**

Used for standard Draft content.

Keeping these separate makes the event much easier to understand.

## What happens to Libra Tokens after the event?

Stellar: Libra is a limited event chapter currently scheduled through **October 22, 2026**.

Players should therefore treat Libra Tokens as **event-specific** unless the live game later gives them another use.

Do not assume the Token becomes a permanent FC Mobile currency after Libra ends.

Through the event's live progression and reward paths shown in your account.
