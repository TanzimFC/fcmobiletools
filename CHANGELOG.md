# FCMOBILETOOLS Changelog

Updates to the tools and features available on FCMOBILETOOLS, written for the people who use the site.

## 24–26 October 2026

### 🚀 New
- **Browser alerts:** Sign up for website notifications, including alerts about new redeem codes.
- **Redeem-code alerts:** Get notified when new codes are published, so you don't have to keep checking the page.

### ✨ Improvements
- **Notification setup:** Clearer permission prompts and more helpful messages when browser alerts can't be enabled.
- **Redeem Codes:** Preserved code information more reliably when a refresh fails.

## 20–23 October 2026

### 🚀 New
- **Giveaway entry and proof uploads:** A clearer way to enter giveaways and submit the required proof.
- **Giveaway updates:** Entry requirements now make the one-entry-per-person rule clear.

### ✨ Improvements
- **Giveaway reviews:** More specific guidance when submitted proof needs to be corrected.
- **Winner reveal:** Improved result display and replay experience.
- **Browsing experience:** Temporarily turned off ads across the site while reviewing page performance and the overall experience.

## 6–15 October 2026

### 🚀 New
- **Member profiles:** Set up a profile and keep track of your activity.
- **Quests and rewards:** Track eligible activities, achievements, daily check-ins, and rewards.
- **Community submissions:** Send reports with screenshots when extra context helps explain an issue.
- **Captain Tracker voting:** Take part in community votes.

### ✨ Improvements
- **Daily check-in:** Clearer timing and more reliable updates when a new check-in becomes available.
- **Tournament results:** Improved match results and progression through knockout rounds.
- **Community reviews:** Better feedback when a submission needs attention.

## 26–30 September 2026

### 🚀 New
- **Gauntlet Mode Planner:** A dedicated tool to help plan your Gauntlet Mode progress.

### ✨ Improvements
- **Team OVR Calculator:** Improved squad planning, substitute handling, and formation feedback.
- **Redeem Codes:** Clearer code search and status information.
- **Events & Reset:** More reliable event schedules and reset times.
- **Page speed:** Reduced unnecessary loading work on key pages.

### 🐛 Fixes
- Fixed layout issues affecting the Team OVR Calculator on mobile screens.
- Fixed problems with search highlighting on the Redeem Codes page.
- Fixed event timing and display issues.

## 18–23 September 2026

### 🚀 New
- **Shards Counter:** Track your FC Mobile shards with a dedicated tool.
- **Events & Reset hub:** Find event schedules and reset information together in one place.

### ✨ Improvements
- **Event timing:** Improved countdowns and local-time display.
- **Football Centre:** Updated match, analysis, and Team of the Week sections.
- **Articles:** Improved article images, formatting, and reading layouts.

### 🐛 Fixes
- Fixed event countdowns that could show inconsistent times.
- Fixed content display issues across Football Centre sections.

## 12–17 September 2026

### 🚀 New

- **Training Calculator:** Work out the training materials needed to upgrade players.
- **Rank Up Calculator:** Estimate the resources required to rank up players.
- **Redeem Codes archive:** Browse published codes and search for the ones you need.
- **Team OVR Calculator:** Plan a squad and see how changes affect its overall rating.

### ✨ Improvements
- **Redeem Codes:** Added clearer code status, search, and browsing controls.
- **Blog and guides:** Improved article discovery and search.
- **Site navigation:** Made the main tools easier to find.

### 🐛 Fixes

## 11 September 2026

### ✨ Improvements
